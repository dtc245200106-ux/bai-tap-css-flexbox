flex-grow: 0; — Tất cả item giữ nguyên kích thước, không giãn ra.

3. Chỉ Item 2 có flex-grow: 1

Item 2 { flex-grow: 1; } — Chỉ Item 2 giãn ra, các item khác giữ nguyên.

4. Tỷ lệ: flex-grow 1 - 2 - 3

flex-grow: 1 / 2 / 3; — Item giữa rộng gấp đôi item 1, item 3 rộng gấp ba item 1.

5. Kết hợp: flex-basis: 100px + flex-grow: 1

6. Layout thực tế: Sidebar + Content

Sidebar { flex-grow: 0; flex-basis: 250px; } và Content { flex-grow: 1; } — Sidebar cố định, Content chiếm phần còn lại.
Sidebar (250px, grow: 0)
Content (grow: 1)

7. Layout 3 cột: 1 - 3 - 1

flex-grow: 1 / 3 / 1; — Cột giữa chiếm 3 phần, hai cột bên mỗi cột 1 phần.
Cột trái (grow: 1)
Cột giữa (grow: 3)
Cột phải (grow: 1)
